# 🚀 InnoSoft Creation - Plateforme Professionnelle

## ✨ Vue d'Ensemble

Plateforme moderne, élégante et futuriste pour **InnoSoft Creation**, spécialisée dans les Technologies de l'Information et de la Communication (TIC).

## 🎯 Ce qui a été créé

### ✅ Frontend React.js
- **Architecture complète** avec TypeScript
- **Design System** professionnel (couleurs, typographies, composants)
- **5 pages principales** : Home, Services, About, Portfolio, Contact
- **Composants réutilisables** : Header, Footer, Sections
- **Animations premium** avec Framer Motion
- **Responsive design** adapté à tous les écrans
- **Navigation fluide** avec React Router

### ✅ Backend Laravel
- **API RESTful** complète
- **Controllers** pour Services, Projets, Contact
- **Système d'email** pour les formulaires de contact
- **CORS configuré** pour la communication frontend
- **Architecture modulaire** et scalable

### ✅ Design System
- **Palette de couleurs** : Bleu-cyan (primary), Violet (secondary), Orange (accent)
- **Typographies** : Poppins (headings), Inter (body), JetBrains Mono (code)
- **Composants UI** : Buttons, Cards, Inputs avec effets glass
- **Animations** : Float, Glow, Gradient, Scroll animations
- **Documentation complète** du design system

## 🚀 Démarrage Rapide

### Backend
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
