# InnoSoft Creation - Plateforme Professionnelle

Plateforme moderne et haut de gamme pour InnoSoft Creation, spécialisée dans les Technologies de l'Information et de la Communication.

## 🎨 Design System

### Identité Visuelle
- **Style** : Moderne, futuriste, professionnel, premium
- **Philosophie** : Innovation, élégance, performance

### Couleurs Principales
- **Primary** : Gradient bleu-cyan (#0066FF → #00D4FF)
- **Secondary** : Violet profond (#6C5CE7)
- **Accent** : Orange énergique (#FF6B35)
- **Dark** : Noir profond (#0A0E27)
- **Light** : Blanc pur (#FFFFFF)

### Typographie
- **Headings** : Inter / Poppins (Bold, SemiBold)
- **Body** : Inter (Regular, Medium)
- **Code** : JetBrains Mono

## 🏗️ Architecture

### Backend (Laravel)
- API RESTful
- Architecture modulaire
- Sécurité renforcée
- Performance optimisée

### Frontend (React.js)
- Composants modulaires
- Design System intégré
- Responsive design
- Animations fluides

## 🚀 Installation

### Backend
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Frontend
```bash
cd frontend
npm install
npm start
```
